# Review form (default)

Used when no venue form is supplied. Replace with the real form when one exists.

### Paper Summary

One paragraph, 5-7 sentences, near-layman language.

### Strengths

Numbered. Each 1-2 sentences with a `(Lines ...)` citation.

### Weaknesses

Numbered. Each 3-5 sentences: judgement, then evidence with a citation, then
what would fix it.

### Questions

Numbered. Each states what the reviewer would update if answered convincingly.

### Ratings

| Dimension | Score | Justification |
|---|---|---|
| Soundness | /4 | 2+ evidence references |
| Presentation | /4 | 2+ evidence references |
| Contribution | /4 | 2+ evidence references |
| Overall | /10 | consistent with the above |

### Confidence

/5, with the reason.
